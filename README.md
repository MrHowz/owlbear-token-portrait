# Token Portrait 1.5.2

## หน้าตาแบบ Edit Stats

ปรับพื้นหลังแผงให้โปร่งใส กลมกลืนกับเมนูของ Owlbear ใช้ Roboto ช่องขอบมนและปุ่มแถวสีอ่อนตามแนวทางของ Edit Stats
แผงสูง 340px ใช้โทนมืด/สว่างตาม Theme API และคงทุกคำสั่งไว้ในเมนูสามจุด
Roboto รวมในไฟล์ build โดยไม่โหลดจาก Google Fonts ระหว่างใช้งาน ใบอนุญาตอยู่ใน public/licenses/roboto.txt

## ใช้จากเมนูสามจุดของ Token

เลือก Token → เปิดเมนูสามจุด → **Portrait ›**

คำสั่งทั้งหมดอยู่ในแผงย่อยเดียวภายใน context menu ของ Owlbear:

- ตำแหน่ง ซ้ายล่าง / ขวาล่าง
- ขนาด 32–1600 พิกเซล กรอกตัวเลขได้ทีละ 1 พิกเซล หรือใช้แถบเลื่อน
- แสดง / ซ่อนภาพ
- เลือกรูปจากคลัง Owlbear ด้วย image picker มาตรฐาน
- ใส่ลิงก์รูปภาพ HTTPS แล้วบันทึก
- ล้างรูปที่ผูกไว้

รุ่นนี้ไม่ลงทะเบียน Tool, Mode หรือ Action ในแถบเครื่องมือด้านข้าง
เมนู Portrait ใช้ `OBR.contextMenu` พร้อม `embed` ซึ่งทำให้ Owlbear แสดงเป็นเมนูย่อยแบบลูกศร
กรอบและการเปิด/ปิดเมนูจัดการโดย Owlbear ส่วนช่องควบคุมภายในเป็นฟอร์มเรียบๆ ใช้สีตาม Theme API
SDK ไม่มี API ที่สร้างช่องตั้งค่าภายใน submenu ให้ทั้งหมดโดยตรง จึงต้องใช้ embedded controls
ไม่มีหน้าต่างตั้งค่าแยก และการเปิดเมนูไม่เปลี่ยนเครื่องมือที่กำลังใช้งาน

## อัปเดต GitHub / Cloudflare

1. แตก `token-portrait-source-1.5.2.zip`
2. อัปโหลดไฟล์และโฟลเดอร์ภายในทับที่ root ของ repository เดิม แล้ว Commit
3. Cloudflare Pages ใช้ build command `npm run build`, output `dist`, root เว้นว่าง
4. รอ deploy สำเร็จ ตรวจ manifest URL เดิมให้แสดง version `1.5.2`
5. โหลดห้อง Owlbear ใหม่ เพื่อยกเลิก background รุ่นเก่าและรับเมนูใหม่

มีการล้าง toolbar registration จากรุ่น 1.2 ระหว่างเริ่มทำงาน
ถ้าไอคอนเก่ายังค้าง ให้รีโหลดห้องหลัง Cloudflare deploy เสร็จ
รุ่นนี้เพิ่มไฟล์ `panel.html` ซึ่งต้องอยู่ในไฟล์ที่ deploy ด้วย
source ZIP ใช้กับ Git integration; deploy ZIP ใช้กับการโฮสต์ไฟล์ที่ build แล้ว
ยังไม่มีการอัปโหลดหรือ deploy ไปยังบัญชีของคุณจากโฟลเดอร์นี้

## แสดงให้ทุกคนเห็น (DM)

เลือก Token ที่ผูกรูปแล้ว → สามจุด → Portrait → เปิด **แสดงให้ทุกคนเห็น · DM**
เมื่อเปิดไว้ ภาพจะตาม Token ที่ DM กำลังเลือก ไม่ใช่ปักภาพ Token เดิมไว้ตลอด ปิดสวิตช์หรือยกเลิกการเลือกเพื่อหยุดแสดง
สวิตช์นี้แสดงเฉพาะบทบาท GM และตรวจบทบาทจาก Owlbear ก่อนเปลี่ยนค่า ผู้รับตรวจบทบาทจาก Party API อีกครั้ง จึงไม่รับ flag แชร์จากผู้เล่นธรรมดา
ผู้เล่นในห้องที่เปิดใช้ Extension รุ่นนี้จะแสดงภาพแชร์ โดยไม่ต้องเปิดแผง Portrait ค้างไว้
DM แสดงเฉพาะภาพส่วนตัวหนึ่งฝั่งตามที่ตั้งไว้ จึงไม่เห็นภาพซ้ำสองข้าง การส่งภาพให้ผู้เล่นยังทำงานตามเดิม
ในมุมมองผู้เล่น ภาพแชร์แสดงคู่กับภาพส่วนตัวในมุมตรงข้ามเสมอ เช่น ผู้เล่นเลือกซ้ายล่าง → ภาพ DM อยู่ขวาล่าง
ขนาดภาพใช้ค่าที่แต่ละคนตั้งไว้ และสวิตช์แสดงภาพส่วนตัวไม่ปิดภาพที่ DM แชร์ บนจอแคบจะแบ่งพื้นที่ให้สองภาพไม่ทับกัน

**Token ที่ปิดตา (`visible: false`) จะไม่แสดงในโหมดแชร์ แม้ผู้รับเป็น DM** รวมถึง Token ที่ผูกกับวัตถุแม่ซึ่งซ่อนอยู่
หาก Token ถูกลบ ไม่ผูกรูป เลิกเลือก ปิดฉาก หรือ DM ออกจากห้อง/เปลี่ยนเป็นผู้เล่น ภาพแชร์จะหายไป
การตรวจนี้อิงสถานะซ่อนรูปตาของ Owlbear ไม่ได้ตรวจว่าภาพถูกบังด้วย Fog หรือถูกซ่อนเฉพาะคนโดยส่วนขยาย vision อื่น
โหมดส่วนตัวของ DM ยังดูภาพ Token ที่ซ่อนได้ตามเดิม
หากหลาย DM เปิดแชร์พร้อมกัน ระบบเลือกแสดงหนึ่งภาพจากผู้แชร์ที่มี Token ใช้ได้ตามลำดับ connection ID เพื่อให้ทุกคนเลือกตรงกัน

เก็บเฉพาะสวิตช์แชร์ใน player metadata และอ่าน selection/role จาก Owlbear โดยตรง ไม่ส่ง URL รูปเพิ่มผ่าน broadcast
ผู้ที่เข้าห้องภายหลังอ่านสถานะปัจจุบันได้จาก Party API; scene items เป็นแหล่งตรวจรูปและสถานะซ่อนเสมอ
อ้างอิง: [Player API](https://docs.owlbear.rodeo/extensions/apis/player/) และ [Party API](https://docs.owlbear.rodeo/extensions/apis/party/)

## ภาพเด้งขึ้นจากด้านล่าง

ตั้งจุดกำเนิดกรอบ Owlbear เป็นด้านล่างเพื่อให้กรอบขยายขึ้น และรอ transition ของกรอบก่อนเริ่มภาพ
หลังโหลดภาพสำเร็จ ภาพจะเลื่อนขึ้นจากด้านล่างพร้อมเด้งเบา ๆ แล้วหยุดนิ่ง ใช้เวลาประมาณ 520 มิลลิวินาที หลังรอ transition ของกรอบ 500 มิลลิวินาที
ใช้กับทั้งภาพส่วนตัวและภาพแชร์ การ pan/zoom ไม่เปิด popover ซ้ำจึงไม่เริ่มแอนิเมชันใหม่
หากระบบ/เบราว์เซอร์ตั้ง `prefers-reduced-motion: reduce` ภาพจะแสดงทันทีโดยไม่เคลื่อนไหว

## ตำแหน่งและขนาด

บนจอคอม ภาพอยู่ห่างขอบล่าง 8 พิกเซล โดยเว้นพื้นที่แถบเครื่องมือด้านข้างและแถบกลางล่างไว้
จอแคบยังยกภาพขึ้นเพื่อหลบเครื่องมือด้านล่าง พื้นที่แถบกลางที่เว้นไว้เป็นค่าประมาณ ไม่ใช่การตรวจจับทุกแผงแบบอัตโนมัติ
กรอกขนาดแล้วกด Enter หรือออกจากช่อง หรือเลื่อนแถบแล้วปล่อยเพื่อบันทึก
ขนาดที่ระบุเป็นขนาดสูงสุดของด้านที่ยาวที่สุด ระบบจะย่อเมื่อพื้นที่มุมจอไม่พอ โดยรักษาสัดส่วนและไม่ตัดภาพ
ค่าขนาดเดิม 180/240/300 พิกเซลยังใช้ต่อได้

## รูปและการตั้งค่า

รูป Portrait ผูกกับ metadata ของ Token เดิม รูปและตำแหน่ง Token ไม่ถูกแก้
Token ที่ยังไม่ผูกรูปจะไม่แสดง Portrait เลือกหลาย Token แล้วผูกภาพจะใช้ภาพเดียวกันทั้งหมด
ใช้ PNG/WebP โปร่งใสถ้าต้องการไร้พื้นหลัง ระบบไม่ลบกรอบ/พื้นหลังภายในไฟล์ภาพ
URL ต้องเป็น HTTPS ของรูปโดยตรงที่เปิดดูได้โดยไม่เข้าสู่ระบบ
ต้องมีสิทธิ์แก้ไข Token จึงผูกหรือล้างรูปได้

การแสดง/ตำแหน่ง/ขนาดบันทึกเฉพาะผู้ใช้ในเบราว์เซอร์ การเลือก Token ไม่บังคับภาพของคนอื่น
เมื่อเปิดแผงจะจำ Token ที่เลือกไว้ ถ้าเปลี่ยน Token หรือฉากระหว่างเลือกภาพ จะไม่บันทึกไปยัง Token ใหม่
รูปเป็น Popover ที่ยึดพิกัดหน้าจอ จึงไม่มีการชดเชยกล้องเมื่อ pan/zoom
พื้นที่ iframe ของ Portrait อาจรับคลิกแทนแผนที่ด้านหลัง และยังต้องรับ selection จากเครื่องมือของ Owlbear

## ทดสอบ

Node.js 22.18+:

```sh
npm ci
npm test
npm run build
npm run dev -- --port 5190
```

`/qa/index.html` เป็น SDK adapter สำหรับตรวจ panel จริงและ controller
`/qa/panel-fit.html` ตรวจแผงกว้าง 320/240/280 px ในธีมมืด/สว่าง
หน้าทดสอบไม่รวมใน production build
ผลทดสอบอยู่ใน QA.md: unit tests, TypeScript/Vite และ browser adapter
ตำแหน่งของเมนูและ lifecycle ของ image picker ภายใน Owlbear จริงยังต้องตรวจในห้องจริง

API: https://docs.owlbear.rodeo/extensions/apis/context-menu/
